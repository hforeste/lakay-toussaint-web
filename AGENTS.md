# Codex Guidance

## Verification

Before a final response for any user-facing website, content, design, form, donation, program, event, resource, privacy, navigation, imagery, or site metadata change, verify the work.

Use these verifiers when relevant:

- Build/type verifier: run the repo's appropriate validation command when the change affects code behavior.
- Blueprint Officer verifier: use the `blueprint-officer` skill for any UI or content change that could affect alignment with the Lakay Toussaint website blueprint.

Treat `docs/blueprint/lakay-toussaint-website-blueprint.md` as the local version-controlled blueprint/spec, and `docs/blueprint/implementation-decisions.md` as the local clarification file.

When Blueprint Officer applies, include one concise result in the final response:

- `Blueprint Officer check: Pass`
- `Blueprint Officer check: Pass with notes: ...`
- `Blueprint Officer check: Needs revision: ...`
